CAMUS: Refinement of ML models via iterative artN searches
==========================================================

*One must imagine Sisyphus happy.*

This is a work-in-progress repository for the `CAMUS` algorithm for automatizing refinement of ML models via iterative artN searches.

Installation
----------------------------------

The following installation procedure was tested:

.. code:: shell

        conda create -n camus python=3.10
        conda activate camus
        python -m pip install -e .

After installation, run

.. code:: shell

        camus init
